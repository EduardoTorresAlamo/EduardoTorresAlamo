## 📌 Projects

**[agenda-os](https://github.com/EduardoTorresAlamo/agenda-os)**
Barbershop appointment system with a WhatsApp bot for customer notifications. Built with Next.js, Supabase, and the Meta WhatsApp Business API.

**[Really-CRM](https://github.com/EduardoTorresAlamo/Really-CRM)**
CRM for real estate agents. Includes client management, property matching with Claude AI, and automated email follow-ups.

**[Task-Flow](https://github.com/EduardoTorresAlamo/Task-Flow)**
iOS task manager built with SwiftUI and SwiftData. Integrates with Calendar and Reminders via EventKit.

**[Turn-Management-System](https://github.com/EduardoTorresAlamo/Turn-Management-System)**
Queue and turn management system for service businesses.
